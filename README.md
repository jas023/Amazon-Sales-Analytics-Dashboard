# 📦 Amazon Sales Analytics Dashboard

## 📊 Overview

An interactive **Power BI dashboard** designed to analyze Amazon sales data and provide insights into sales performance, products, customers, and business trends.

## 🎯 Key Analysis

* Sales & Revenue Performance
* Product Category Analysis
* Customer & Order Analysis
* Sales Trends Over Time
* Top & Low Performing Products
* Regional/Business Performance

## 🛠️ Tools Used

* **Power BI**
* **Power Query**
* **DAX**
* **Excel/CSV**

## 📈 Dashboard Features

* Interactive slicers and filters
* KPI cards
* Dynamic charts and visualizations
* Product and sales performance analysis
* Trend analysis
